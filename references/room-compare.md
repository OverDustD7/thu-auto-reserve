# 研讨间/房间 · 学生活动室 vs 图书馆研讨间（差异对比 + 推荐规则）

> 用途：当用户提出「研讨间 / 讨论 / 开会 / 借个房间 / 办活动」等**未指明系统**的需求时，agent 不要立刻逼问「是哪家的」。应先了解基础信息，把**两个相似资源都介绍、说清差异、给出推荐**，最终由用户确定去哪个（见 `SKILL.md`「零·甲」）。
> 本文件是差异速查与推荐规则，供 agent 面向用户讲解时引用——**只讲自然语言，不暴露脚本/命令/API**。

## 一、一句话定位

| | 学生活动室（学生清华） | 图书馆研讨间（IC 空间） |
|---|---|---|
| 是什么 | 校团委管理的**活动用房**（C楼 / 南区地下 / 胜因院22号） | 图书馆内的**研讨/自习空间**（北馆 / 文科馆 / 西馆音乐 / 法律馆） |
| 本质 | **审批制**：提交申请 → 审核 → 通过后微信通知 | **即时预约**：提交即成功，到馆签到即用 |

## 二、差异对比（面向用户讲解用）

| 维度 | 学生活动室 | 图书馆研讨间 |
|---|---|---|
| 适合做什么 | 社团活动 / 班会 / 排练 / 舞蹈 / 录音 / 文化 / 学术报告（**活动性质，用途广**） | 小组讨论 / 自习 / 备考 / 音乐练习 / 面试答辩（**研讨/学习性质**） |
| 要不要审批 | **要**（提交后审核，最晚「使用日期前 3 天」出结果） | **不要**（提交即成功） |
| 是否适合「马上要用」 | 否（审批有周期；且需提前 ≥4h / ≥3天） | 是（提前 3~5 天内可约，即时确认） |
| 提前量 | C楼/南区 提前≥4h；胜因院 提前≥3天；距开始 ≤14 天 | 单人研读间 3 天内；团体/音乐/研讨舱/双人舱 5 天内（含当天） |
| 单次时长 | ≤2h；每人每日 1 次 | 30 分–4h（双人舱 ≤2.5h）；每天最多 1 个有效预约 |
| 人数 | 容量跨度大（有小研讨室，也有十几人/几十人的大房间）；**如实申报人数** | 偏小：单人 / 双人 / 2–4（研讨舱）/ 3–10（团体）/ 音乐 3–18；**成员按学号实名** |
| 位置 | C楼 / 南区地下 / 胜因院22号 | 图书馆内（北馆 / 文科馆 / 西馆音乐 / 法律馆） |
| 开放时段 | C楼/南区 7:00–23:00；胜因院 9:00–21:00 | 研读/研讨/双人舱 08:00–22:00；音乐研讨间 08:30–21:30 |
| 要填什么 | 主办方 / 主题 / 人数 / 活动类型(7类) / 活动内容（**要写申请文案**） | 选成员（学号）+ 日期时段，**无需写文案** |
| 签到/违约 | 无签到；通过后微信通知、可看密码锁 | 预约后 **20 分钟**内刷卡/扫码签到，否则记违约+自动取消；违约累计 3 次暂停 30 天 |

## 三、推荐规则（根据用户实际需求推荐，但不代用户选择）

| 用户情况 | 更可能合适 | 理由 |
|---|---|---|
| 今天/明天就要用 | 图书馆研讨间 | 即时确认；活动室审批最晚「使用前 3 天」才出结果，来不及 |
| 办活动/社团/班会/排练/演出/文化/学术报告 | 学生活动室 | 用途广、有审批背书 |
| 自习/备考/小组讨论(2~4人)/音乐练习/面试答辩 | 图书馆研讨间 | 即时、无需写文案、无需审批 |
| 人数多（>10 人） | 学生活动室 | 图书馆研讨间一般 ≤10（仅音乐研讨间最多 18） |
| 需要 >2h 连续时段 | 图书馆研讨间 | 活动室单次 ≤2h |
| 想要正式审批背书（如答辩、比赛） | 学生活动室 | 审批通过即正式 |
| 就在 C楼/南区/胜因院 附近 | 学生活动室 | 位置就近 |
| 就在图书馆 | 图书馆研讨间 | 位置就近 |

> 推荐**只是建议**，最终去哪家、选哪间房由**用户确定**。房间目录见 `references/activity-rooms.md`（活动室 51 间）与 `references/lib-space-spaces.md`（图书馆研讨间）。

## 四、通用流程（需求未指明系统时）

1. **先了解基础信息**：多少人？哪天、什么时间段（笼统即可）？大概多久？做什么（用途）？有无位置偏好？
2. **两边都介绍 + 说清差异**：挑「差异对比」里与用户需求相关的几条讲（**不要只列其中一项**）。
3. **给出推荐 + 理由**：按「推荐规则」给一个倾向并说明为什么；**推荐后必须明确问用户选哪个**（如「我推荐图书馆研讨间，你确定吗？还是想了解学生活动室？」），不要只说「建议走X」就往下查。
4. **用户最终确定**：**必须等用户明确回答去哪家**，再进入对应分支（活动室=第八节 / 图书馆研讨间=第九节）继续「查房→查可约→选房→确认→提交→提交后告知」；**绝不能因推荐了某家就跳过用户确认、直接进该分支查可约**。
