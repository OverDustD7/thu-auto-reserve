# thu-auto-reserve —— 清华大学自动预约（体育场馆 + 学生活动室 + 图书馆 IC 空间 + 图书馆自习座位）

帮清华学生/教职工自动预约四类资源：**体育场馆、学生活动室、图书馆 IC 空间、图书馆自习座位**。**你只需用自然语言说出需求，它帮你查、推荐、下单。**

## 能帮你做什么

| 分支 | 能做什么 | 你只需要做 |
|------|---------|-----------|
| 🏟 **体育场馆** | 推荐运动、查可约时段、打开预约页、抽签报名、查/取消预约 | 登录（一次性）、拖一次滑块、扫码支付 |
| 🏫 **学生活动室** | 一次列出 51 个活动室、按人数/用途推荐、查可约、API 提交申请、查看/撤销/清草稿 | 微信登录一次「学生清华」小程序（之后约 7 天免登录） |
| 📚 **图书馆 IC 空间** | 预约研讨间/考研座位/活动/外借设备/电子阅览室、查时段、查看/取消 | 登录（一次性），预约时核对成员+时间 |
| 💺 **图书馆自习座位** | 查各馆舍实时剩余、推荐馆舍、打开选座页点选、取消座位 | 登录（一次性），选座页点选座位 |

## 典型对话示例

- 「我明天下午想约羽毛球」→ 查时段、打开预约页，你拖滑块 + 扫码即可。
- 「2 人小组讨论，明天下午借个研讨间」→ 先问清需求，把**学生活动室与图书馆研讨间两边都介绍 + 说清差异 + 给推荐**，你确定去哪家后再查可约、选房、确认提交。
- 「去图书馆自习，哪里有空座」→ 先问借书/自习条件，按需推荐馆舍（或「随便选」），打开选座页你点选。
- 「看看我约了什么 / 撤销这笔」→ 列出你的预约/申请、帮你撤销。

## 特点

- **四类预约一站式**：体育场馆、学生活动室、图书馆 IC 空间、图书馆自习座位，一次搞定。
- **高度自动化**：查询 / 推荐 / 可约全走 API，不用你一个个点。
- **自然语言交互**：你只用说需求，不用记命令。
- **隐私安全（设计考量）**：登录态**加密**保存、**保留约 7 天**、token 不外泄；参与人数**如实申报**——这些是刻意的安全考量，而非折衷。

## 使用须知

- 体育场馆、图书馆 IC 空间、图书馆自习座位登录都走**清华统一身份认证（SSO）**，一次性登录后复用。
- 体育场馆支付是微信 / 支付宝扫码；活动室首次需微信登录一次「学生清华」小程序，之后脚本优先从微信进程实时提取登录态（微信开着即免登录），本地保存的登录态保留约 7 天（与后端 jwt 有效期对齐）。
- **隐私安全**：登录态（token/会话）会**加密**保存在本机，且**保留约 7 天**；参与人数**如实申报**。请在本人设备使用、注意保管，不用他人账号。
- 可预约时段 / 空座实时变化，预约前建议重新查询。
- 图书馆自习座位需预约后 30 分钟内刷卡签到；图书馆 IC 空间/自习座位各有违约规则，请按时到馆；老馆座位无需预约、可直接前往。

## 完整功能清单

### 🏟 体育场馆（`www.sports.tsinghua.edu.cn`）

| 功能 | 说明 |
|------|------|
| 登录 | 一次性 SSO 登录，之后免登录复用 |
| 查运动项目 | 列出全部可预约的运动 |
| 查场馆/场地 | 查某运动下的场馆、设备类型、场地 |
| 查可预约时段 | 一次查「普通预约（先到先得）+ 抽签场次」 |
| 推荐运动 | 按你的身体/目标/预算/室内外等需求打分推荐 |
| 预约 | 自动打开预约页、选好日期时段，你只需拖一次滑块 + 扫码支付 |
| 查看预约 | 列出我的预约记录（含支付状态） |
| 取消预约 | 一键取消（有「提前 24 小时」限制） |
| 抽签报名 | 报名 / 查场次 / 查中签 / 缴费（纯 API，无滑块） |

### 🏫 学生活动室（「学生清华」微信小程序）

| 功能 | 说明 |
|------|------|
| 前置检查 | 一键确认登录态是否可用 |
| 列出全部活动室 | 一次列出 51 个活动室（名称/位置/容量/用途） |
| 推荐房间 | 按人数/用途/位置推荐，自动避开录音/导播/舞蹈/排练等专属功能房 |
| 查占用 | 查某活动室已被占用/申请中的时段 |
| 查可约时段 | 查指定日期区间内可约时段（按各位置规则过滤） |
| 提交申请 | 两步提交（默认只预览，确认后才真正提交；提交前自动校验时段/人数/时长） |
| 查看我的申请 | 列出申请中 / 被拒的申请 |
| 查看草稿箱 | 单独看未提交的草稿 |
| 撤销申请 | 一键撤销（自动清理草稿） |
| 删除草稿 | 清空草稿箱里不用的申请 |
| 记住主办方 | 保存一次，之后申请自动复用 |

### 📚 图书馆 IC 空间（`cab.lib.tsinghua.edu.cn`）

| 功能 | 说明 |
|------|------|
| 登录 | SSO 登录（可换号、绑邮箱） |
| 查空间类型 | 研讨间/座位/考研座位/活动/外借设备/电子阅览室 |
| 推荐空间 | 按用途推荐（小组讨论→研讨间、自习→座位、备考→考研座位…） |
| 查可约时段 | 列出某类型下各房间编号/人数/空闲时段 |
| 预约 | 校验规则后提交预约（你确认后完成；纯 API，无需填写网页弹窗） |
| 查看/详情/取消 | 查我的预约、看详情、取消 |

### 💺 图书馆自习座位（`seat.lib.tsinghua.edu.cn`）

| 功能 | 说明 |
|------|------|
| 登录 | SSO 登录（复用浏览器会话） |
| 查馆舍剩余 | 各馆舍实时剩余/总量（老馆免预约、可直接前往） |
| 推荐馆舍 | 按借阅需求/自习条件推荐，或「随便选」 |
| 列楼层/阅览区 | 馆舍→楼层→阅览区→可约时段 |
| 选座 | 打开选座页，你在座位图点选（绿=空闲） |
| 查/取消 | 我的预约、取消（每日限 1 次） |
